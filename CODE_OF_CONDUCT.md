# Code of Conduct

This project adopts the [Contributor Covenant](https://www.contributor-covenant.org/) as its
Code of Conduct. The authoritative text of the covenant lives at
<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>.

**By participating in this project you agree to read, understand, and follow that covenant.**

The covenant is intentionally _not_ reproduced here so that this file stays a stable pointer
rather than a copy that can drift from the upstream version. All questions about the Code of
Conduct — including reports of unacceptable behaviour — go to the maintainers at the private
address listed in [SECURITY.md](./SECURITY.md), so that reports are handled confidentially.
